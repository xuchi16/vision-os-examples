# visionOS Examples

Curated examples to learn visionOS

# Structure

Each course section contains folders with the following content:

- **Section 1 – Preparation**: Pre-class materials and reading
- **Section 1 – Projects**: Hands-on projects to be coded during the class
- **Section 1 – Live Code**: The actual code written during the live session

- **Section 2 - Preparation**: Second section of the course

---

_This structure organizes visionOS learning into a progressive workflow, with pre-class preparation, in-class coding projects, and live code references for each section._
